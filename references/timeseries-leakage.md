# 时序特征工程与数据泄漏防护

**第一步该做什么**：先做泄漏自查（下表红旗任一中招即停），再优化指标。金融/时序任务指标"好得离谱"几乎必然是泄漏。

## 泄漏检测判据（可判定，已确认）

- 分类准确率 >70%（金融/加密场景）→ 几乎必然泄漏；真实 edge 的准确率在 52–58%。
- `features.corrwith(target)` 任一特征 >0.5 → 可疑。
- 回测 65% 但实盘 50% → 泄漏确认。
- 特征在 t 时刻用到了 t 之后的信息（含：全样本 z-score、全样本归一化、目标编码用了全量、shuffle 后切分）。

## 归一化铁律

时序归一化只能用 **rolling / expanding / ewm** 统计（只用历史窗口），全样本 z-score = lookahead。

## 特征工程规范

- 样本量经验法则：每特征 10–20 样本；特征数 < N_samples/15；特征选择只能在训练折内做。
- 平稳性：`adfuller(series.dropna())[1] < 0.05` 才算平稳；价格→log return、OBV→斜率、持有者数→变化量。
- 目标构造：`close.shift(-N)/close - 1`；二分类阈值典型 1%(1h) / 3%(4h) / 5%(日线)；中性区样本剔除。
- 特征目录（~40 个公式）按需向原材料 `feature-engineering/references/` 查询：动量、波动率、量价、链上、微结构五族。

## 时序验证：walk-forward（已确认参数）

- 训练 720 bars、测试 168 bars、步长 24、**gap = 前视 horizon**（防标签泄漏到下一折）。
- 禁止随机 k-fold；滚动窗口逐折前进；每折指标汇总时报告均值 ± 标准差，不只报最优折。

## 概率校准与阈值（金融信号分类）

- 阈值按 profit factor 网格搜索（0.50–0.85 步长 0.01），典型最优 0.60–0.75；不要默认 0.5。
- 树模型概率校准 isotonic 优于 Platt；校准集独立于训练集。

## 如何证明"没有泄漏"而非碰巧没漏

① 特征时间戳审计：逐特征回答"t 时刻这行数据在现实中已存在吗"；② 反向测试：把目标整体 shift(+1) 后模型应该废掉——废不掉说明有特征偷看了未来；③ 泄漏修复后指标必然下降，记录下降幅度作为真实 edge 的估计。反向测试是金标准。
